Follow these rules whenever writing markdown:
- Use a single **hyphen (-)** followed by a space for bullet points.
- Put body content directly after a header, **with no blank line** in between.
- Write **mostly in prose**. Don't overuse headers and bullets — reach for them when comparing options or explaining structure, not by default.
- Tag code blocks with a language (e.g. ` ```tsx `).
- Use **bold** only for genuine emphasis, not as a habitual decoration on every line.
